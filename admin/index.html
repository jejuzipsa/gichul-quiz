관리자 로그인

사이트 현황을 확인하려면 관리자 비밀번호를 입력해.

아직 관리자 인증 서버가 설정되지 않았어. Vercel 환경변수와 저장소를 연결하면 로그인할 수 있어.

관리자 2단계 인증

Microsoft Authenticator에서 확인한 6자리 코드를 입력해.

Microsoft Authenticator → 계정 추가 (+) → 기타 계정 → 수동으로 코드 입력

계정 이름: 공인중개사 사이트 (admin)

이 키는 절대로 다른 사람에게 보내지 마. QR 생성 사이트에도 입력하면 안 돼.

관리자 보안 기록

      
관리자 로그인 성공은 매번 기록해. 처음 보는 기기·IP는 확인 표시가 붙어. 실패한 로그인과 비밀번호 변경도 별도 기록돼.

IP와 브라우저로 실제 접속자를 확정할 수 없어. 낯선 관리자 로그인이 있으면 즉시 비밀번호를 변경하고 세션 인증키도 재발급해야 해. 이 화면은 실시간 알림을 보내지는 않아.
