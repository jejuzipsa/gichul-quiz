# 자동차정비산업기사: 원본 이미지 기반 데이터 재구축 (2026-11-22)

## 결정
기존 QA1~QA5에서 생산한 원문 텍스트의 OCR 품질이 신뢰하기 어려워, **문제 본문·보기·해설 데이터의 채택을 전면 중단**한다. 기존 텍스트는 새 은행에 **한 글자도 재사용하지 않는다**. 기존 QA 기록은 검수 이력으로만 남고 새 원본(source of truth)이 아니다.

## 원본 스크린샷으로 재구축한 결과
- 원본 캡처 57 PNG 중 바이너리 완전 중복 2장 제외 → 고유 55장
- 새 위치 분할 처리: 회색 해설 패널 기준으로 **문제 영역 720개** 식별
- 회차/과목: 9회 × 4과목 × 20문항 = 720 슬롯, ID 고유 720개
- **문제와 보기 원본 이미지 720개**, **해설 원본 이미지 720개** 별도 추출
- 원본 화면의 빨간 정답표 36개를 처음부터 독립적으로 위치 검출하고 각 20칸의 번호를 컴퓨터 비전 글리프 매칭으로 판독
- 새로 판독한 정답표 숫자 720개를 앞선 원본 육안 검사 기록과 **사후 대조만** 진행: 불일치 0
- 정답의 기술적·논리적 정확성은 **인증되지 않음**
- 새 텍스트 자동 인식 작업은 환경 시간 제한으로 **87/720 문항 이후 중단**, 남은 문항의 텍스트를 추정하거나 이전 QA OCR 텍스트로 채우지 않음
- 새 JSON의 텍스트 필드는 `null`, 원본 이미지 경로와 키 번호는 분리 보관, `publishable=false` 유지
- 개인용 로컬 이미지 문제풀이 초안: 번호 선택 → 원본 정답표 채점 → 원본 해설 보기, 모바일/데스크톱 레이아웃, 별도 녹색 테마
- 코드 데이터 구조 및 ZIP 파일 무결성 확인. 브라우저 GUI 동작에 대한 자동화 테스트는 미완료

## 다음 단계
- 원본 이미지 단위로 독립적인 고정밀 비전 전사/수작업 대조를 진행할 것
- 질문·선택지·해설 모두 원본과 비교해 검수하고, 기술적 정답은 제조사 정비자료 등으로 별도 검증
- 재검증한 문항만 승인하도록 상태 분리: 이미지가 정확한 것과 내용이 옳은 것은 별개
- 출판사 원문 및 문제 이미지는 공개 저장소에 커밋하지 않음. 데이터는 사용자가 보관하는 비공개 패키지로만 제공

## 저작물 취급
공개 저장소에는 이 문서와 일반 구조·검증 코드만 저장한다. 출판사 문제·해설의 원문/이미지/JSON은 공개하지 않으며, 비공개 운영도 저작권 이용 허락 여부를 대신하지 않는다.
