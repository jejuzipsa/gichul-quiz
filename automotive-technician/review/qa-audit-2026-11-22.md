# 자동차정비산업기사 720문항 OCR 품질 감사 — 2026-11-22

**결론: 출제·배포 금지. 원본 대조 전수 검수가 필요함.**

## 대상
- 사용자가 제공한 2026년판 예상/복원문제 PNG 57장 (고유 55장, 완전 중복 2장)
- 9회 × 4과목 × 20문항 = 720문항의 JSON OCR 초안
- 판독 대상: 문제·보기·해설·원본 정답표. 정답표 추출값은 720개 모두 미검증.

## 발견
| 분류 | 수 | 의미 |
| --- | ---: | --- |
| 문항 슬롯/ID | 720 / 고유 720 | 구조상 36세트 각 20문항 보존 |
| 기존 OCR 검토 표시 | 174 | 검토가 필요하다고 이전에 기록한 문항 |
| 추가 자동 품질검사 의심 | 300 | 기존에 문제없다고 표시했던 문항에서 발견; 확정 오류 수 아님 |
| 하나 이상의 검토 표시가 있는 문항 | 474 | 중복 제외한 수 |
| 정답표 인식 저신뢰 | 104 | 104개는 특히 원본 정답표 재대조 필수 |
| 20번 해설 후미에 정답표 OCR 잡음 | 36 | **36세트 전체에서 실제 확인** |
| 유사 지문 후보 | 13쌍 | 질문 조건/보기 다른 사례 포함; 자동 삭제 금지 |

## 원본과 직접 대조된 예
- `auto-r01-s01-q01`: 2번, 4번 선택지의 OCR이 손상됨(제조사 권장 밸브 간극 조정 시기).
- `auto-r01-s01-q02`: '출력'을 엉뚱한 알파벳으로 오인.
- `auto-r01-s01-q04`: 'ECU', '스캔 툴'을 숫자/문자 파편으로 오인.
- 36개 문제 세트의 20번 해설 끝마다 정답표 인식 결과가 붙음.

**수정본 QA-v2 ZIP**(사용자 개인 파일 라이브러리에 별도 보관)은 원본 OCR 초안과는 별개로, 위 4곳의 직접 대조 교정 및 36개 해설의 정답표 뒷부분 제거를 반영했음. 이 수정은 **720문항의 전체 텍스트·정답 검수 완료를 의미하지 않는다.** 모든 문항의 `answer_verified=false`, `review_status=needs_review`, `publishable=false` 유지.

## 후속 검수 절차
1. 과목별 20문항씩 원본 PNG와 JSON을 나란히 대조.
2. 문항 지문과 선택지 4개 전수 확인(문자 오인식·줄바꿈·보기 분리).
3. 정답표 번호 1~20 재확인, 104개 저신뢰 항목 우선 검증.
4. 해설과 정답의 논리적 일치 및 전문기술 정확성 별도 검증.
5. 유사 지문 후보 13쌍은 선택지/조건까지 비교한 후 병합 여부 결정.
6. 항목별로 사람의 검수 근거가 남기 전까지 서비스 출제 비활성화.

## 저장소/법적 분리
`gichul-quiz`는 공개 저장소다. 따라서 출판사의 원본 문제·정답·해설 또는 해당 OCR 텍스트는 이 PR에 공개 커밋하지 않는다. GitHub에는 구조, 검사 코드, 숫자 중심의 QA 보고서만 둔다. 비공개 보관을 하더라도 이용범위 확인이 필요하다.

## 정답표 확대 육안 대조 및 기술검수 추가 결과
- 저신뢰 정답표 104칸을 실제 원본 이미지를 확대해 대조함.
- 그중 **80건의 OCR 정답 번호를 원본에 맞게 수정**, 24건은 원래 숫자와 일치.
- 별도 인식 고신뢰 표본 72칸(9회 × 4과목 × 2문항)도 원본과 대조: 표본에서 불일치 0건.
- 결과적으로 정답표 원본을 확대 확인한 칸은 **176/720**, 나머지 **544칸은 아직 미확인**.
- 주의: 원본 정답표와의 숫자 일치는 **문제 자체의 정답이 기술적으로 옳다는 검증이 아님**.
- 해설과 문제 원문 OCR의 전수 검증도 미완료이므로 **720개 모두 출제 보류**.
- `auto-r01-s01-q02`는 원문 보기 중 복수의 잘못된 설명 가능성이 있어 별도 **내용 검수 우선 대상**으로 지정함. 터보차저 제조사 기술 자료의 작동 원리와 비교할 것: https://www.garrettmotion.com/knowledge-center-category/oem/what-is-a-turbo-and-how-does-it-work/
- 사용자의 개인용 QA-v3 산출물에는 정답표 교정 80건의 변경 기록과 176건의 확인 목록을 남김. 이 공개 PR에는 출판사 원문 데이터 미포함.

## QA4 재확인 (2026-11-22)

- **원본 정답표 전수 재대조 720/720**: QA3에서 기확인한 176개 외 나머지 544개를 원본 캡처에서 잘라 6개 확대 검사표로 육안 대조.
- 새로운 기계 판독 이견 17건은 원본 글리프 확인 결과 모두 **기계 판독 오류**로 판정. QA3 기준 정답 번호 추가 변경 **0건**.
- **원문 교정 작업 일부 실시**: 1회/자동차 엔진정비 20문항의 문제·보기 4개·해설을 원본 이미지와 대조했고, 19문항 총 41개 텍스트 필드를 정정.
- **지문·보기·해설 미확인 700문항**. 초기 OCR 품질 문제로 전수 대조가 필요.
- **내용·정답 타당성 우선 검토 7문항**(질문/해설의 조건 부족·복수 오답 가능성 등): `auto-r01-s01-q02`, `auto-r01-s01-q05`, `auto-r01-s01-q07`, `auto-r01-s01-q11`, `auto-r01-s01-q16`, `auto-r04-s03-q09`, `auto-r04-s03-q11`.
- 앞서 식별된 유사문제 13쌍 **자동 삭제하지 않음**. 특히 `auto-r04-s03-q09`와 `q11`은 질문 조건은 거의 같지만 정답과 보기 구성이 달라 고위험 검토가 필요함.
- **정답표와의 일치 ≠ 기술적 정답 검증**. 모든 720개 `answer_verified=false`, `publishable=false` 유지.
- 비공개 개인용 QA4 ZIP은 사용자 대화에서 제공, 원문은 공개 저장소에 올리지 않음.

## QA5 추가 정밀감사 — 2026-11-22

**이 기록은 개인정보/구매 출판사 원문을 포함하지 않음. 원문과 OCR 추출 JSON은 별도 비공개 백업.**

### 작업 범위
- 720문항 전체: ID·회차·과목·보기 4개·정답 1~4·해설 유무·출제 보류 플래그 **구조 검사 완료**, 구조상 누락 0.
- 정답표 숫자: QA4 원본 720/720 대조 결과 유지(정답 *내용* 검증은 별개).
- **원본 이미지 육안 대조 100문항**: 1회 4과목 80문항 + 2회 엔진정비 20문항.
- 이번 원문 대조에 따른 변경 내역: **171개 텍스트 필드 / 64문항**. 문항 텍스트는 비공개 QA5 ZIP에 변경 로그로 보관.
- **원문 대조 미완료 620문항 / 정답·해설 기술적 전수 승인 0문항**. 전체 출제 보류 유지.

### 추가 기술적 위험 26문항 (기존 7 포함)
**사실에 반하는 설명이 발견된 사례**
- `auto-r02-s01-q06`: 연료탱크 안의 압력 조절기 불가능이라고 안내. Ford/GM 등 리턴리스 연료 시스템에서는 연료탱크 내 펌프 모듈에 위치.
- `auto-r02-s01-q10`: 디젤 글로우 플러그를 일반적으로 고전압 처리 부품으로 설명. NGK 제품별 정격은 수 V~12V대.
- `auto-r01-s01-q02`: 터보차저의 배출가스 '정화' 선택지로 복수 오답 가능.

**안전상 우선 검토**
- `auto-r01-s04-q02`, `auto-r01-s04-q16`: 고전압 서비스 플러그 단일 조치를 '최초' 또는 충분조건처럼 설명. 차종별 안전 시퀀스·잔류전압 점검 누락.
- `auto-r01-s03-q12`: 안전장치(SRS 포함) 진단 시 모든 장치를 활성화 상태로 유지하도록 범용 설명. 제조사 SRS 서비스 주의사항과 구분 필요.
- `auto-r01-s03-q07`: ESD 손목띠를 작업자 감전 보호구와 혼동할 수 있는 문항 표현.

**차종별 규격·진단 조건 미지정**
- `auto-r01-s02-q03`: 변속 솔레노이드 12–25Ω을 범용 정상값으로 제시(다른 차종에 5.0–5.6Ω 사례).
- `auto-r01-s02-q09`, `auto-r01-s02-q14`: 전자 현가 센서·조향각 센서 출력 전압을 차량 모델 없이 표준값으로 단정.
- `auto-r01-s01-q05`, `auto-r01-s03-q20`: 차종·고장코드·측정 조건 없는 '최초 점검 부품' 단정.
- `auto-r01-s04-q10`: 순서 문제와 선택지 형식이 일치하지 않음.
- `auto-r01-s04-q14`: 전력 효율 평가 질문에 DTC 조회를 정답으로 제시.
- `auto-r04-s03-q09`/`q11`: 고압·저압 모두 상승한 동일 에어컨 조건에 서로 다른 단일 정답.
- 그 외 문항은 비공개 QA5 `QA5-technical-findings.json`에 분류·참고 출처 기록.

### 기타 자동 품질검사 (문항 수, 실제 오류 확정 아님)
