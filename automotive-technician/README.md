# 자동차정비산업기사 문제은행 섹션 (비공개 데이터 분리)

기존 공인중개사 기출문제 사이트의 UI/풀이 로직을 재사용하기 위한 **독립 자격증 설정·검증 구조**다. 기존 공인중개사 문제 데이터와 학습 기록은 변경하지 않는다.

## 문제 트랙
- `past-exams`: 2012–2020년 공개 기출 자료(수집/이용 범위 확인 후 별도 구축)
- `publisher-expected`: 사용자가 제공한 2026년판 민간 복원·예상문제 (9회 × 4과목 × 20문항 = 720문항, **OCR 검수 전 초안**)
- `concept-quiz`: 해설의 개념·원리를 검증해 자체 작성한 괄호/객관식 문제

## 보안과 작업 상태
이 저장소(`jejuzipsa/gichul-quiz`)는 **공개** 상태이므로, 스캔한 출판사 문제 원문과 추출 JSON, OCR 원문, 정답·해설은 GitHub의 이 공개 저장소에 올리지 않는다.

원문 데이터는 별도 비공개 저장소 또는 개인용 로컬 학습 저장소로 옮겨야 한다. 비공개 저장소라도 사용권한 확인이 필요하며, 공개 배포는 별도 검토 대상이다.

### 검수 전 데이터 통계 (2026-11-22)
- 원본 캡처: 57장 / 완전 중복 2장 / 고유 55장
- 36개 과목별 세트, 720문항 텍스트·4지선다·해설 추출(자동 OCR)
- 정답표 후보: 720개 / 낮은 인식 신뢰 104개
- OCR/정답표 우선 검수 표시: 174문항 (여러 오류가 중첩될 수 있음)
- 중복된 이미지 2건 제외, 문장 유사 문제 후보 13쌍은 **자동 삭제하지 않음**
- **전수 검증 완료 아님**: 모든 문항의 정답과 기술 설명은 검수 전 상태, 출제 금지

## 개발 연결
- `config.json`: 과목 및 기본 테마(기존 공인중개사 사이트와 다른 색상)
- `schema.json`: 추출 문항 형식
- `validate-bank.mjs`: JSON 구성 및 누락 검사. `node automotive-technician/validate-bank.mjs <비공개 데이터 폴더>`
- `private-data/`, `source-scans/`: 공개 Git에 커밋 금지

실제 비공개 데이터 JSON 및 원본 OCR 자료는 사용자 대화에서 전달된 ZIP 산출물로 별도 보관. 이 브랜치는 **사이트 배포와 데이터 공개를 수행하지 않는다**.
