공인중개사 기출문제 사이트 - 누적 PATCH NOTES
============================================================

문서 목적
- 기출문제 사이트 전체의 기능 변경, 데이터 변경, 검수, 구조 변경을 한 파일에서 누적 관리한다.

- 세부 검수자료는 review/ 아래에 남기고, 이 파일에는 전체 프로젝트 흐름과 중요한 결정사항을 요약한다.

------------------------------------------------------------
1. 초기 프로젝트 기반
------------------------------------------------------------

- 공인중개사 기출문제 전용 반응형 웹사이트로 시작.
- 모바일과 PC에서 같은 문제은행을 사용하는 구조로 설계.
- 6과목 분류:
  · 부동산학개론
  · 민법 및 민사특별법
  · 공인중개사법령 및 중개실무
  · 부동산공법
  · 부동산공시법
  · 부동산세법
- 객관식 문제만 사용.
- 문제 풀이 후:
  · 정답 선택지는 파란색
  · 선택한 오답은 빨간색
  · 정오답과 관계없이 해설 표시
  · 다음 문제 이동
- 풀이 종료 후 결과와 오답 확인 가능.
- 틀린 문제 다시 풀기 기능을 기본 목표로 설정.
- 초기 단일 HTML 프로토타입에서는 LocalStorage 기반 문제/과목 관리, 개별 문제 입력, CSV/TSV 일괄 입력도 실험.
- 이후 실제 기출문제 데이터 중심 구조로 확장하면서 저장소형 정적 사이트 구조로 정리.

------------------------------------------------------------
2. 기출문제 데이터 구조 정리
------------------------------------------------------------

- data/*.json 을 기출문제 원본(Source of Truth)으로 사용.
- data/*.js 는 file:// 직접 실행을 위한 로컬 미러로 유지.
- JSON 수정 후 tools/rebuild_local_mirrors.py 로 JS 미러를 갱신하는 구조 사용.
- data/manifest.js 에 과목별 문항 수와 연도 범위를 명시.
- 현재 기출문제는 2021~2025년, 총 1,000문항.
- 문제은행 로드 시 과목 일치 및 데이터 형식을 검증하는 로직 추가.
- 2025년 데이터는 기존 데이터 제거 후 문제지 이미지/JPG 소스를 기준으로 다시 정리하는 과정을 거침.

12. 괄호문제 V2 - 검수용 TXT 문제은행 체계
------------------------------------------------------------

작업 목적
- 문제를 생성하자마자 사이트에 넣지 않고 “생성 → TXT 검수은행 → 검수 → 최종 데이터 → 사이트 반영” 순서로 분리.
- 사람이 JSON 1,600개를 직접 읽지 않고, 문제/보기/정답/빈칸정답/해설/원본ID를 한 블록에서 확인할 수 있게 함.
- 수량을 맞추기 위한 의미 없는 문장 변형을 금지.

검수 파일 기본 구조
- ID
- ORIGIN
- STATUS
- TYPE
- CATEGORY
- 문제
- 보기
- 정답번호
- 빈칸 정답
- 해설
- 원본 핵심개념 문제
- 원본 정답
- 검수 메모

문제 작성 원칙
- 긴 설명문 전체를 정답으로 만들지 않음.
- 설명문 안에서 핵심 단어/숫자/기간/주체/요건/효과만 괄호 처리.
- 1개 핵심값이면 단일 빈칸.
- 서로 연결된 값은 A/B/C 다중 빈칸 + 조합형 보기.
- 한 문제는 한두 개 핵심 암기 포인트를 우선.
- 모바일에서 한눈에 비교할 수 있도록 보기 길이를 짧게 유지.
- 일반 핵심개념 485문항은 변경하지 않고 괄호문제만 재작성.
- 오래된 요약 PDF와 현행 법령이 충돌하면 검수된 core와 현행 법령을 우선.
- 아직 V2 문제은행은 사이트 런타임에 반영하지 않음.
