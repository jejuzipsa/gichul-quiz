## 실제 검사 방법 및 결과

- 일반 핵심개념 485문항: 4개 보기, 정답 인덱스 0~3, 보기의 NFKC·공백 정규화 중복, 질문문 완전중복 검사 결과 0건.
- 괄호문제 1,600문항: ID·문제문 완전중복, 원본 핵심개념 485문항의 originQuestionId 연결, 정답 문자열과 보기 포함관계, 1~3개 빈칸 표기 검사 결과 0건.
- 6과목 전체에서 생성된 빈칸문제 정적 JS와 JSON은 동일 문항 객체로 동기화됨. GitHub CI는 원본 TXT와 생성물의 바이트 일치 여부도 별도로 확인.
- **발견된 품질 결함:** 정답이 빈칸 외부 문장에 그대로 드러난 문항 72개(단일 빈칸 69개 + A/B 조합형 3개). 답·보기·원본 ID는 그대로 두고 문제문만 수정. 수정 후 같은 검사에서 정답노출 0건.
- 같은 originQuestionId에서 정답까지 동일한 변형 문제쌍 237개는 실제 존재. *같은 정답을 다른 방식으로 반복 암기하는 문항*이므로 전부 중복/오답 처리하지 않음. 대신 10문항 랜덤 세션에는 동일 originQuestionId가 두 번 선택되지 않도록 개선.
- 일반 핵심개념 485문항과 괄호문제 1,600문항의 2026-10-06~07 과거 감사·승인 상태는 보존. 이 상태만으로 2,085문항의 모든 조문·판례·보기별 법률 내용을 이번에 다시 개별 인증했다고 주장하지 않음.
