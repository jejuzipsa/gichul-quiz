편집 규칙
1. 카드 내용은 TXT만 직접 수정한다.
2. 너무 긴 표나 예외가 많은 내용은 카드로 억지로 만들지 않는다.
3. 시점에 따라 바뀌는 법령·금액·연령·공시일자 등은 1차 카드에서 제외한다.
4. 그래프/도식이 필요한 카드는 [시각화] 키만 기록하고 UI가 해당 키를 렌더링한다.
5. 원문과 다른 교정은 [검수메모]에 근거를 남긴다.
