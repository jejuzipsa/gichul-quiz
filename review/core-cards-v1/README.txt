핵심 단어 카드 TXT Source of Truth v1
====================================

현재 범위
- 과목: 부동산학개론
- 카드: 170장
- 기본 원본: 1.공인중개사요약_부동산학개론.pdf
- 보완 원본: Q-Net 공개 기출, 국가법령정보센터, 국토교통부 토지이음 등
- 정렬: 짧은 일반 용어 → 핵심 개념 → 이론/학자 → 그래프 → 수식/응용
- 상태: 부동산학개론 1차 완성본

원본
- review/core-cards-v1/01_real_estate_intro.txt

문항 블록
- ID
- STATUS
- ORDER
- TYPE: term / concept / theory / graph / formula
- CATEGORY
- SOURCE_KIND: summary / official / summary+official / reference
- SOURCE_PAGE
- SOURCE_SECTION
- SOURCE_REF
- [제목]
- [부제]
- [검색어]
- [핵심]
- [수식]
- [시각화]
- [검수메모]

빌드/검증
- node tools/core-cards/build.cjs
- TXT를 core-cards/data.js로 재생성한 뒤 validator를 실행한다.

편집 규칙
1. 카드 내용은 TXT만 직접 수정한다.
2. 요약집 내용을 기본으로 사용한다.
3. 요약집에 정의가 없는 시험 핵심 기본용어는 공식 기출·법령·공공 용어사전으로 보완한다.
4. 외부 보완 카드는 SOURCE_KIND / SOURCE_REF를 반드시 기록한다.
5. [검색어]는 검색 별칭 전용이다. 비표준 표현을 카드 제목으로 올리지 않는다.
6. 너무 긴 표나 예외가 많은 내용은 카드로 억지로 만들지 않는다.
7. 시점에 따라 바뀌는 법령·금액·연령·공시일자 등은 원칙적으로 카드에서 제외한다.
8. 그래프/도식이 필요한 카드는 [시각화] 키만 기록하고 UI가 해당 키를 렌더링한다.
9. 원문과 다른 교정은 [검수메모]에 근거를 남긴다.

완성본 주요 판단
- 나지: 국가법령정보센터 표준지 조사·평가 기준의 정의로 보완.
- 맹지: Q-Net 2021 제32회 1차 1교시 1번의 옳은 지문으로 보완.
- 건부지: 요약집 p2 건부감가 문맥 + 기출 용어 사용 + 일반 토지용어 정의를 교차검토.
- 택지구역: 카드 제목으로 만들지 않고 표준 학개론 표현인 '택지지역'의 검색 별칭으로 등록.
- 대지·필지·포락지: 현행 법령 정의 우선.
- 선하지·환지·일단지: Q-Net 공개 기출로 정의 확인.
- GPM: 원문 p15의 설명이 CAM과 동일하여 오류 의심 → 계속 제외.
- 다핵심이론: 원문 p6의 '멕켄지'를 사용하지 않고 공식 기출 기준 해리스·울만 유지.
- 시점 민감 제도 수치: 카드에서 제외.
