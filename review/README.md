# 괄호문제은행 수정 — 최신성 검토 보류

## 2026-09-17 적용 범위 변경

사용자가 "법령 세법 검토를 일단 보류하고 수정사항만 적용해줘"라고 요청했다.
이에 따라 준비된 16문항 수정과 고정 데이터 전환, 문제 수 표시 및 구조 검증을 1.50에 적용한다.
전체 문장·법령 검토를 완료했다는 의미는 아니다. 각 문항의 미검토 상태는 그대로 보존한다.
구조 검사와 회귀 검사는 자동 실행하고, 전체 내용 승인을 요구하는 엄격한 검사는
수동 workflow_dispatch에서 실행하도록 분리했다. 검사 결과를 허위로 통과 처리하지 않는다.
아래는 범위 변경 전 초안의 검토 기록이다. 아래의 배포 미승인 및 병합 보류 설명은
이전 단계의 기록이며, 현재 적용 범위는 이 절의 사용자 지시를 따른다.

## 구조 변경

- 편집 원본: `review/blank-bank/*.json`. 문제 ID는 유지했다.
- 브라우저는 `word-quiz/blank-data/*.js`에 고정된 문제만 읽는다.
- 핵심요약 로딩 및 자동 문제 생성을 제거했다. 과거 생성기는 `tools/blank-bank/legacy-builder.js`에 감사용으로 보존했다. 새 빌더는 이를 실행하지 않는다.
- 과목별 전체 개수를 표시한다. 초안에는 내용 검토 중이라고 표시한다.
- 잘못된 과목 키는 파일과 검증 기준 모두 학개론으로 통일한다.
- 누락, 목표 수량 미달, 중복, 빈 정답, 잘못된 선택지에 대해 로딩을 거부한다.
- 문항 내용이 바뀌면 기존 검토 해시가 무효화된다. 법령 문항은 대조 기준일, 출처 URL, 조문 및 시행일 기록이 필요하다.

## 실제 확인한 자료와 한계

첨부 `1.공인중개사요약_부동산학개론.pdf`, `3.공인중개사요약_중개사법.pdf`, `4.공인중개사요약_세법.pdf`의 텍스트와 줄바꿈을 대조했다. 학개론의 현가계수 표, 건부감가의 다음 줄, 교차탄력성 표를 확인했다. 중개사법 원문에는 법인 2억원·개인 1억원, 세법 원문에는 종부세 6억원·9억원과 2016년 말 임대소득 기준이 있다. 이 내용을 현행으로 간주하면 안 된다.

국가법령정보센터에서 다음 최신 시행본의 표제는 확인했다.

- [공인중개사법 시행령, 2026-08-28 시행](https://www.law.go.kr/LSW//lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260828&lsiSeq=288933&urlMode=lsInfoP)
- [지방세법, 2026-07-01 시행](https://www.law.go.kr/LSW//lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260701&lsiSeq=282559&urlMode=lsInfoP)

검색 결과는 법인 4억원·개인 2억원을 제시했으나, 최신 시행본의 본문·부칙을 모두 확보하지 못했다. 웹 도구에는 표제와 메뉴만 내려왔고 브라우저에서도 본문이 빈 상태였다. 따라서 4억원 교정은 후보로만 기록하고 법령 승인은 하지 않았다. 세율·공제액을 기억이나 검색 요약만으로 일괄 치환하지 않았다.

첨부 기출·정답 PDF 및 기존 기출 데이터는 수정하지 않았다. 과거 기출의 당시 정답은 현행법으로 덮어쓰면 안 된다. 공법·공시법의 원문 요약 PDF는 이번 첨부 목록에 없으므로 기존 추출 데이터 이상의 원문 대조도 필요하다.

## 검사와 재개 방법

```sh
node tools/blank-bank/build.cjs --draft
node tools/blank-bank/validate.cjs
node tools/blank-bank/test.cjs
node tools/blank-bank/validate.cjs --release
```

구조 검사는 1600개 전체 통과. 손상 데이터·누락·중복·검토 후 변경 감지 등 118개 확인 통과. 마지막 배포 검사는 **현재 실패하는 것이 정상**이다. 이는 2890개의 내용 오류를 발견했다는 뜻이 아니라, 남은 검토 상태별 미충족 조건의 수다. 브라우저에서 모바일 화면과 10문제 풀이를 끝까지 수행하는 기능 검사는 아직 하지 않았다.

GitHub Actions에 구조 검사와 내용 배포 검사를 추가했다. 저장소의 브랜치 보호 또는 기존 배포 설정을 변경한 것은 아니므로, 이 검사만으로 관리자의 병합이나 직접 배포를 기술적으로 금지한다고 주장하지 않는다. 이 초안은 병합·배포하지 않는다.

재개 시 JSON 1600개를 순서대로 읽고, 문장 완결성·오답의 타당성·답 노출을 개별 판단해야 한다. 숫자 부분문자열 일치는 정답 노출로 자동 판정하지 않는다. 현행 조문과 부칙, 예외를 확보하여 법령 문항의 검토 상태와 출처를 채운다. 같은 설명의 단순 변형으로 부족한 수량을 채우지 않는다. 문장/법령 검토가 모두 끝난 후 은행의 `reviewStatus`를 `approved`로 바꾸고 기본 빌드 및 배포 검사를 통과시킨다.
