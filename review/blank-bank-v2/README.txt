괄호문제 V2 검수용 문제은행

목적
- 사이트에 바로 넣지 않고 먼저 사람이 읽기 쉬운 TXT 문제은행에서 검수한다.
- 일반 핵심개념 문제은행은 수정하지 않는다.
- 현재 main 1.52의 검수된 핵심개념 문제를 출발점으로 삼는다.
- 이 디렉터리의 문제는 모두 PENDING 상태이며 사이트 런타임에는 반영되지 않는다.

파일
- 01_real_estate_intro.txt : 부동산학개론
- 02_civil_law.txt : 민법 및 민사특별법
- 03_brokerage_law.txt : 공인중개사법령 및 중개실무
- 04_public_law.txt : 부동산공법
- 05_registration_law.txt : 부동산공시법
- 06_tax_law.txt : 부동산세법
- manifest.json : 문제은행 메타데이터

검수 단위
각 문제는 아래 정보를 한 블록에 둔다.
ID / ORIGIN / STATUS / TYPE / CATEGORY
문제 / 보기 / 정답 / 빈칸 정답 / 해설 / 원본 핵심개념 문제 / 원본 정답 / 추가 빈칸 후보 / 검수 메모

STATUS
- PENDING : 미검수
- APPROVED : 검수 완료, 현재 seed 사용 가능
- EDIT : 문장/보기 수정 필요
- DROP : 사용하지 않음

EXPAND
- YES : 현재 seed와 별개로 같은 ORIGIN에서 추가 핵심 빈칸을 만들 가치가 있음
- NO : 현재 seed 하나로 충분함

STATUS와 EXPAND를 분리한 이유
- 검수 완료 여부와 추가문제 생성 여부는 서로 다른 상태다.
- 예: STATUS: APPROVED + EXPAND: YES 는 현재 문제는 그대로 사용 가능하지만 같은 원본에서 추가 문제도 만들 수 있다는 뜻이다.

생성 원칙
1. 긴 설명 전체를 정답으로 두는 방식을 사용하지 않는다.
2. 숫자·기간·비율·금액·교육시간 등은 해당 값만 빈칸으로 우선 추출한다.
3. 이론의 인명처럼 서로 연결된 핵심값은 A/B 조합형으로 만들 수 있다.
4. 그 외 정의형은 설명문 속 핵심 용어 자체를 빈칸으로 만든다.
5. 모든 문제는 원본 핵심개념 ID(ORIGIN)를 유지한다.
6. 사이트 반영은 검수 완료 후 별도 컴파일 단계에서만 한다.

현재 단계
- 485개 원본 핵심개념에서 1차 검수용 seed 문제 485개를 생성했다.
- 최종 목표 1,600개는 이 seed를 검수하면서 EXPAND 대상으로 분리해 추가 생성한다.
- 수량을 맞추기 위해 긴 문장 정답이나 의미 없는 중복 변형을 자동 생성하지 않는다.
