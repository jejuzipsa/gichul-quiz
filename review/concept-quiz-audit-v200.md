# v2.00 — 민법 73문항 주제별 선택지 감사 완료 (2026-10-09)

## 범위와 정확한 상태 표현

v1.99 main `9d6db18bd9fe93e01cbbb46e1be6771e73b25061`을 기준으로 민법 최종 21문항 `CVK053~CVK073`을 직접 검토했다. 앞선 v1.95~v1.99에서 이미 선택지까지 교정한 52문항에 더해 **73문항 전체의 문제·정답 위치·보기·해설의 주제 적합성에 대한 1차 내용검토를 완료**했다.

- `CVK053~CVK060` 8문항: 주택임대차보호법 [시행 2026-01-02] 현행 조문 제3~6조의3 대조. 다른 개념에서도 참이던 **24개 선택지**를 같은 법률주제의 명확한 오답으로 교체. 기존 정답지문·정답인덱스·ID 보존, 예외 해설 확장, 이 8문항의 `VERIFIED_AT`·`REVIEWED_AT`만 현재 검토 날짜로 변경.
- `CVK065` 1문항: 합유의 오답에 제275조 총유의 실제 참인 정의가 제시되던 것을 발견했다. 같은 합유 개념 안의 거짓 문장으로 교체하고 제271·275조의 차이를 해설에 명시했다. 답은 1번 그대로. 이 문항의 검토 날짜만 갱신.
- `CVK061~064, CVK066~073` **12문항은 단일 정답 문항 구조와 기본 법조문·요약 정의에 부합해 내용/정답/검토날짜를 수정하지 않았다.** 특히 `CVK061`은 요약 PDF의 학설적 기초 용어로 분류하며, 가상의 조문을 만들지 않는다. 법령 개정 경과조치, 모든 판례 사실관계, 예외의 완전검증을 뜻하지 않는다.
- 이 단계는 문항별 관련 조문·개념의 **주요 주장 1차 대조**이며, 민법 전 범위의 모든 예외·판례·현행성에 대한 영구적 최종 인증을 의미하지 않는다. 자동 구조검사 통과를 법률적 적합성 인증으로 확대하지 않는다.
