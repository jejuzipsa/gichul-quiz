공인중개사 기출문제 로컬 v1.5

실행
- index.html 더블클릭

문제 데이터 구조
- 연도별 통합 파일을 사용하지 않음.
- data 폴더 아래 과목별 JSON 6개가 원본(Source of Truth).

  data/real_estate_intro.json   부동산학개론
  data/civil_law.json           민법 및 민사특별법
  data/brokerage_law.json       공인중개사법령 및 중개실무
  data/public_law.json          부동산공법
  data/registration_law.json    부동산공시법
  data/tax_law.json             부동산세법

- 각 문제에 year, exam, subject, paper, question_number가 들어 있어 연도/회차/과목/교시/원문번호로 구분 가능.
- 2024 + 2025 현재 총 400문제.
- 첫 화면에서는 문제 400개를 전부 메모리에 올리지 않음.
- 과목을 누를 때 해당 과목 데이터만 로딩함.

중요: JSON과 JS가 같이 있는 이유
- 웹/로컬서버: data/*.json을 직접 fetch하여 사용.
- index.html 더블클릭(file://): 브라우저 보안 때문에 JSON fetch가 차단될 수 있어 data/*.js 미러를 로딩.
- 수정해야 하는 원본은 JSON만 보면 됨.
- JSON을 직접 수정한 경우 Python이 있다면 아래 명령으로 로컬용 JS 미러 갱신:
  python tools/rebuild_local_mirrors.py

- 표/그래프/복잡한 수식만 보조 이미지로 남기는 구조를 지원함.
